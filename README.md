## 🧠 About Me

I'm **Ahmed Tarek**, a Computer Engineering graduate and AI Engineer passionate about understanding how intelligent systems work under the hood and transforming that knowledge into real-world applications.

Currently working as a **Part-time AI Engineer at a US-based startup**, where I explore and develop AI-driven solutions.

My journey into AI started with a simple question: *How does something like ChatGPT actually work?*

What started as curiosity about a black box turned into a deep interest in Machine Learning, Deep Learning, Neural Networks, and the engineering behind modern AI systems.

Today, I'm focused on building intelligent applications, experimenting with generative AI, and continuously exploring what's possible with emerging technologies.

- 🔭 **Currently exploring:** LLMs, Generative AI, AI Agents & RAG Systems.
- 🧠 **Core interests:** Machine Learning, Deep Learning, Computer Vision & NLP.

## 🚀 Featured Projects

A few projects where I experiment, learn, and turn ideas into working solutions.

### 🎨 [Zypher AI – Intelligent Logo Generator](https://gsshunterai.github.io/Zypher_AI/)

An AI-powered logo generation platform that transforms business descriptions into professional logo concepts through a conversational interface.

- Fine-tuned FLUX.1-schnell using LoRA.
- Integrated Mistral-powered conversational AI.
- Developed an agentic workflow for prompt enhancement and reference gathering.
- Built a full-stack application with Flask and database integration.

**Tech:** Python · FLUX.1 · LoRA · Mistral · Flask · PostgreSQL · Firebase

### 🧬 GANs & Synthetic Data Research

Exploring Generative Adversarial Networks and their impact on deep learning performance.

- Implemented GAN architectures using PyTorch.
- Experimented with Fashion-MNIST generation.
- Investigated the impact of GAN-generated synthetic data on CNN classification performance.

**Tech:** Python · PyTorch · PyTorch Lightning · CNNs · GANs

### 🏥 Diabetes Prediction Web Application

A machine learning application that predicts diabetes risk using patient-related features.

- Experimented with Logistic Regression, SVM, and Gradient Boosting.
- Developed a prediction interface using Flask.
- Applied machine learning workflows for model evaluation and deployment.

**Tech:** Python · Scikit-learn · Flask · Pandas

### 💳 Credit Score & Default Risk Prediction

A machine learning solution for financial risk analysis and credit default prediction.

- Worked with 84 financial features across 1,000 customer records.
- Implemented regression and classification models.
- Developed a Flask API to serve model predictions.

**Tech:** Python · Scikit-learn · Flask · Machine Learning

### 🎬 Movie Recommendation System

A recommendation engine built using neural network embeddings to explore personalized recommendations.
